# Templates

Files to copy into a katax API (`src/<same path>`). They complement what `katax init` generates; where a file has
the same name as a generated one, the template replaces it with the same exports plus what the standard adds.

| Template | Replaces / adds | What it gives |
| --- | --- | --- |
| `shared/db.ts` | replaces generated `db.ts` (keeps `db()`, `withTransaction`, `Tx`) | `SqlExecutor` for repository functions, `lockKey()` advisory lock |
| `shared/db-errors.ts` | adds | `isUniqueViolation(err, constraint?)`, `isForeignKeyViolation`, `isCheckViolation` |
| `shared/jwt.utils.ts` | replaces generated `jwt.utils.ts` (same exports) | HS256 pinned, 32-char minimum, secrets read lazily |
| `shared/secret-compare.utils.ts` | adds (use instead of `secureCompare`) | `safeTokenEquals()` constant-time compare |
| `shared/rate-limit.store.ts` | adds | `RedisFallbackStore`: Redis counters, atomic Lua, memory fallback, `RATE_LIMIT_REDIS_NAME` |
| `middleware/rate-limit.middleware.ts` | adds; replace the inline limiter in `app.ts` | `apiLimiter`, `authLimiter`, `refreshLimiter` |
| `shared/job-lock.utils.ts` | adds | `runExclusive(name, job)` for cron jobs |
| `config/cookie.config.ts` | adds | refresh cookie options (path `/api/auth`, `COOKIE_SAME_SITE`) |
| `middleware/no-store.middleware.ts` | adds | `Cache-Control: no-store` for `/api/auth` |
| `types/db.types.ts` | append to generated `db.types.ts` | `CountRow`, `IdRow` |
| `registry/dashboard-registry.ts` | adds (needs `axios`) | HTTP registry + heartbeat for the Katax dashboard |

All of them typecheck inside a project generated by katax-cli 1.7.1 (`strict`), and `db.ts`, `job-lock.utils.ts`
and `rate-limit.store.ts` were run against PostgreSQL 16 and Redis with concurrent calls.
